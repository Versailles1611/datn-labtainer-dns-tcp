BAI LAB: TCP SEQUENCE PREDICTION HIJACKING
==========================================

BOI CANH
--------
He thong gom 3 may ao tren cung mot mang LAN (172.21.0.0/24):

  - victim   (172.21.0.2): may nan nhan, dang mo phien TCP toi server.
  - server   (172.21.0.3): dich vu TCP, cho phep ket noi tu victim.
  - attacker (172.21.0.4): may cua ke tan cong (ban), co san scapy,
    tcpdump de doc phien TCP truoc khi chen goi tin.

NHIEM VU CUA BAN (muc do TRUNG BINH)
-------------------------------------

Buoc 1. Tren attacker, thuc hien ARP spoofing de giua victim va server:
  
      cd ~/.local/bin
      sudo nohup ./arp-poison eth0 >/tmp/arp.log 2>&1 < /dev/null &
      disown
  
  Kiem tra tren victim: ip neigh | grep 172.21.0.3 phai thay dia chi
  172.21.0.3 tro toi MAC cua attacker (02:42:ac:15:00:04).

Buoc 2. Tren attacker, sniff phien TCP de doan bao dau SEQ/ACK:
  
      sudo tcpdump -Z root -U -n -w ~/session.pcap 'tcp port 9999'
  
  De cua so chay, tren victim gui them du lieu: echo PROBE | nc -w 3 172.21.0.3 9999

  De doc capture (Ctrl+C truoc cua so tcpdump hoac mo terminal khac):
      sudo tcpdump -nn -r ~/session.pcap
  
  Tim so sau:
    - SEQ hien tai cua victim (chu ki hien tai)
    - ACK hien tai cua server
    - Cordon nguon (sport) cua victim
  
  *Phuong phan doan doan: SEQ tiep theo = SEQ hien tai + do dai payload + 1

Buoc 3. Tren attacker, chen goi tin du lieu gia t value du doan vao phien:
  
      sudo python3 pred-hijack.py <seq> <ack> <sport> <payload_len>
  
  Trong do:
    - <seq> = so sequence hien tai cua victim (tu pcap)
    - <ack> = so acknowledgment hien tai cua server
    - <sport> = cordon nguon cua victim
    - <payload_len> = do dai payload can chen (vi du: 6 byte cho "HELLO\\n")
  
  Vi du: sudo python3 pred-hijack.py 2452713155 4262428 48844 6

  Goi tin du chen se duoc server chap nhan va gui ngược ACK.

  Kiem tra tren server: sudo cat /var/log/session.log phai chua thong diep duoc chap nhan.

Buoc 4. Kiem tra ket qua:
  
      checkwork
  
  De xem 3 checkwork: gui tin du lieu, server da chap nhan, ARP chinh xac.

KIEM TRA KET QUA
----------------
Tu Linux host, chay lenh:

    checkwork

De xem 3 checkwork: gui tin du lieu, server chap nhan, ARP chinh xac.

KET THUC
--------
Khi hoan thanh, chay:

    stoplab

LUA CHON THU TU THUC HANH:
1. Phao yen: arp-poison -> sniff -> doan SEQ/ACK -> chen goi tin du doan
2. Tat pkill hoac dong terminal giua trinhieng, vi viec sniff va chen goi tin phai dam bao ket noi con tro.
3. Cach doan tan cong: SEQ tiep theo = SEQ hien tai + do dai payload + 1.
