BAI LAB: DNS ZONE TRANSFER
==========================================

BOI CANH
--------
He thong gom 3 may ao tren cung mot mang LAN (172.21.0.0/24):

  - victim   (172.21.0.2): may nan nhan, chua client DNS thu cong.
  - dns-server (172.21.0.3): may chu DNS BIND9, chua domain example.com.
  - attacker (172.21.0.4): may cua ke tan cong (ban), co san dig, tcpdump.

NHIEM VU CUA BAN (muc do TRUNG BINH)
-------------------------------------

Buoc 1. Tren attacker, kiem tra DNS server co phuc vu zone transfer khong:
  
      dig @172.21.0.3 AXFR @172.21.0.3 example.com
  
  Hoac:
      dig @172.21.0.3 AXFR 172.21.0.3
  
  Kiem tra ket qua: co gom the nap toan bo cat luu domain example.com khong?

Buoc 2. Neu zone transfer duoc cho phep, doc cac cat luu:
  
      dig @172.21.0.3 AXFR example.com > /tmp/zone.txt
  
  Kiem tra /tmp/zone.txt chua:
    - SOA record (Start of Authority)
    - Toan bo cat luu cua domain example.com
    - NS records
    - A records cua cac may

Buoc 3. Neu zone transfer KHONG duoc phep (thuc te), server se tra loi loi:
  
      ; Transfer failed
  
  Hoac se chi ra loi: denial

Buoc 4. Kiem tra tren dns-server: named.conf.local de hieu cach thay doi cau hinh:
  
      cat /etc/bind/named.conf.local
  
  Nhan nap them dong:
    zone "example.com" IN {
        type master;
        allow-transfer { none; };  // Chỉ phep transfer trong miễn phí
    }

KIEM TRA KET QUA
----------------
Tu Linux host, chay lenh:

    checkwork

De xem 4 checkwork: cw_zone_xfer_offered, cw_zone_xfer_allowed, cw_zone_xfer_success, cw_soa_record.

KET THUC
--------
Khi hoan thanh, chay:

    stoplab

Luu y: Zone transfer le nguy hiem vi cho phep ke tan cong lay cat luu toan bo may chu.
Nhieu cung cap DNS dat allow-transfer { any; } hoac allow-transfer { ; } trong named.conf.
Cau hinh hop le: allow-transfer { 127.0.0.1; }; (chi phep tu localhost).

THU TU THUC HANH:
1. Phao yen: Kiem tra zone transfer da dang -> Doc SOA -> Kiem tra cat luu
2. Neu khong the transfer: Kiem tra named.conf.local de xac thuc cau hinh
3. Tat pkill hoac dong terminal giua trinh tien.
